# Trabajar en este módulo

Este repositorio es propietario de su código y sus pruebas. Consulta los
[contratos canónicos de core](https://github.com/dbravoan/dbcms-core/tree/main/docs).
PHP y Composer se ejecutan en Docker. Usa bases y archivos desechables para
pruebas de instalación. Reutiliza el kit admin compartido y conserva las decisiones
de publicación, privacidad, idioma y mercado.

Comandos y publicación: [mantenimiento](docs/MAINTENANCE.md).
